# SSHyar 1.0.0

SSH, SFTP, and server tools in one desktop window — **no agent on the host**.

## Download

Installers are attached to this release (built by CI):

- **Windows:** `.msi` (recommended) or setup `.exe`
- **Linux:** `.AppImage` or `.deb`

Requires an OpenSSH client on the machine.

## What’s in 1.0

- Terminal + graphical SFTP together (Follow shell, Compose bar when applicable)
- Optional Docker, Nginx, systemd, cron, and Monitor panels
- Local encrypted vault with optional master password and portable backup
- In-app update: download the installer, then click **Update**
- Product docs in [English](../README.md), [فارسی](../README.fa.md), [العربية](../README.ar.md), [Русский](../README.ru.md), [简体中文](../README.zh-CN.md)
