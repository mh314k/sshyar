## Show HN / general English

**Title:** Show HN: SSHyar – SSH, SFTP, and server panels with no agent on the host

**Body:**

SSHyar is an open-source desktop SSH helper for Windows and Linux.

One window: terminal + graphical SFTP + optional Docker / Nginx / systemd / cron / Monitor panels. Profiles live in a local encrypted vault. Nothing is installed on the server (no agent, no `.sshyar` folder).

In-app updates download the installer from GitHub Releases.

- Repo / README: https://github.com/mh314k/sshyar  
- Download: https://github.com/mh314k/sshyar/releases/latest  

## Reddit (r/selfhosted, r/sysadmin, r/opensource)

**Title:** SSHyar 1.0 – desktop SSH + SFTP + Docker/host panels, zero remote footprint (Windows/Linux, GPL)

**Body:**

I built SSHyar as a day-to-day SSH desktop app: connect, browse files, and poke Docker/Nginx/systemd without juggling three tools or dropping an agent on the host.

- Local encrypted vault + portable backup  
- Optional plugins per profile  
- In-app installer download when a new release ships  

Screenshots and comparison notes are in the README: https://github.com/mh314k/sshyar  

Feedback and issues welcome.
